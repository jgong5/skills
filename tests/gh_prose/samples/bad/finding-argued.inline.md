`thread` sorts on `submittedAt`, which is null for a pending review, so the sort raises `TypeError`. I reproduced this locally by creating a pending review on a scratch PR and running the script against it, and it crashed every time. I think this is quite important, because the orchestrator calls this on every pass and a single crash would stop the whole run, which is exactly the kind of failure the design tries to avoid. Drop entries with no `submittedAt` before sorting.
