# Project principles

This repository's layer on top of agent-team's
[default principles](skills/agent-team/principles.md). It overrides none of
them.

## A count stop on a converging change is a mis-estimate

When a line count or a review-round count trips its stop and each round fixed
a real, new problem, accept the count as a mis-estimate and review the head as
it is; do not cut correct code or re-cut the task to fit the number. The stop
exists to catch a stuck task, and a task that keeps converging is not one.
Rulings: [#77](https://github.com/jgong5/skills/issues/77#issuecomment-6191417135),
[#238](https://github.com/jgong5/skills/pull/238#issuecomment-6812597845),
[#233](https://github.com/jgong5/skills/pull/233#issuecomment-6811512868).
